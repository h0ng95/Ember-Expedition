# IGNIS: ASHEN OATH · 이그니스: 잿빛 서약

가로 화면의 도트 그래픽으로 만드는 Android 자동 전투 로그라이트. 제목은 개발 가칭이다.

## 최신 반영 내용

- **전장 대화 · v0.59** — 보스전 뒤 이그니스가 빛 조각으로 나타나고 실제 동료들이 작은 도트 말풍선으로 대화한다. 탭으로 넘기기·건너뛰기와 상세 기록을 연결하고, 이그니스와 원정대의 서약을 정리했다.
- **전투 가독성 · v0.58** — 심하게 가려진 아군에 윤곽·번호를 표시하고, 왼쪽 초상화를 누르면 전장에서 위치를 강조한다.
- **공격 타이밍 · v0.58** — 원거리 발사 자세와 투사체 출발을 맞추고, 피격으로 공격 모션이 끊겨 보이던 문제와 연사 후속타 모션을 수정했다.
- **용 보스 · v0.57** — 긴 바닥 예고에는 연속 불기둥, 원형 예고에는 공중 브레스가 이어진다. 브레스 끝을 예고 원에 맞추고 일반 공격의 입가 불꽃을 제거했다.
- **성장 화면 · v0.56** — 진화·결합 전후의 모습을 크게 비교하고, 성장이 완료되는 연출을 추가했다.

[최신 변경과 검증 기록](docs/design-v0.59/HANDOFF.md)
