# IGNIS: ASHEN OATH · 이그니스: 잿빛 서약

가로 화면의 도트 그래픽으로 만드는 Android 자동 전투 로그라이트. 제목은 개발 가칭이다.

## 최신 반영 내용

- **후반 장면과 엔딩 · v0.62** — 폐광의 장부, 성당의 물길, 정원의 회복 흔적과 용의 구속 해제를 연결했다. 첫 완주 뒤 세 장면 엔딩이 이어지며 결과와 이야기 기록에서 다시 볼 수 있다.
- **아트 통일 · v0.62** — 이그니스와 소품을 굵은 도트로 바꾸고, 큰 물건 진열 대신 보스와 환경의 반응이 먼저 보이도록 배치했다. [아트 일관성 기준](docs/art-direction.md)을 이후 제작에도 적용한다.
- **첫 숲 장면 · v0.60** — 쓰러진 잿갈기 곁에 작은 생물이 다가오고, 이그니스 아래 새싹을 본 실제 동료들이 공격을 멈춘다. 시즌1의 여섯 장면과 엔딩 대본을 정리했다.
- **전투 가독성 · v0.58** — 심하게 가려진 아군에 윤곽·번호를 표시하고, 왼쪽 초상화를 누르면 전장에서 위치를 강조한다.
- **용 보스 · v0.57** — 긴 바닥 예고에는 연속 불기둥, 원형 예고에는 공중 브레스가 이어진다. 브레스 끝을 예고 원에 맞추고 일반 공격의 입가 불꽃을 제거했다.

[최신 변경과 검증 기록](docs/design-v0.62/HANDOFF.md)
