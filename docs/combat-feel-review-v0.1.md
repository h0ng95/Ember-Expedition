# 전투 타격감 검토 · Slotbound 영상과 현재 시안

2026-10-18 · 심층 원정대 UI 시안 01 후속 검토

## 1. 판단

**현재 캐릭터의 개성과 색감은 유지할 수 있다. 전투용 스프라이트는 작은 장식을 덜고, 공격과 피격이 읽히도록 다시 제작하는 쪽을 권한다.**

현재 시안에서 가장 먼저 고칠 부분은 공격 동작·체력 감소·피해 숫자의 타이밍이다. 지금 구현으로는 목표한 타격감을 평가할 수 없다. 캐릭터 단순화만으로 이 문제가 해결되지는 않는다.

우선순위는 **명중 반응 연결 → 공격·피격 애니메이션 → 무기별 이펙트와 소리 → 다수 전투의 가독성 → 캐릭터 세부 묘사 조정**이다. Slotbound 수준의 완성도를 달성했는지는 움직이는 시제품과 실제 휴대폰에서 검증해야 한다.

- [게이머비누 실제 플레이 영상 · 19분 56초부터](https://www.youtube.com/watch?v=2g7oBmbbPAs&t=1196s). 19:56 부근의 근접 교전과 20:01 부근의 피격 장면을 비교했다. 영상 전체를 시청한 것은 아니다.

이번 검토는 영상의 시각적 연출과 현재 프로젝트 코드에 근거한다. 사운드의 질감·믹싱은 평가하지 않았다. 정확한 히트스톱 시간, 카메라 흔들림의 적용 규칙, 원작의 애니메이션 구현 방식은 확인하지 않았다.

## 4. 현재 시안이 약하게 보이는 이유

검토 대상: `ui/app.js`, `ui/style.css`, `ui/assets/expedition-sprites-v2.png`.

| 현재 구현 | 전투에서 생기는 문제 | 수정 방향 |
| --- | --- | --- |
| 한 장의 캐릭터 이미지를 좌우로 이동 | 준비·휘두르기·반동이 구별되지 않는다 | 무기와 몸의 자세가 달라지는 공격 프레임을 만든다 |
| 경과 시간에 비례해 HP가 계속 감소 | 언제 맞아서 얼마나 닳았는지 연결이 약하다 | 실제 명중 이벤트에서 HP를 감소시킨다 |
| 공격 표시와 피해 숫자가 서로 다른 주기로 발생 | 화면의 반응이 한 번의 타격으로 묶이지 않는다 | 공격 판정·섬광·피격 동작·숫자·소리를 같은 이벤트로 연결한다 |
| 캐릭터 좌표에 긴 CSS 이동 보간 적용 | 다가가서 때리는 동작이 미끄러지는 느낌을 줄 수 있다 | 이동과 공격 돌진을 별도의 동작으로 다룬다 |
| 적 전원이 7초 뒤 동시에 쓰러지고 보상 화면 진입 | 마지막 일격과 처치의 여운이 부족하다 | 각 적의 실제 HP에 따라 처치하고 짧은 정리 구간을 둔다 |

이 시안은 화면 흐름을 확인하는 약 7초의 연출이며, 실제 전투 시스템이나 애니메이션의 완성도를 보여주는 결과물은 아니다.

## 5. 캐릭터 디자인 조정안

### 유지할 것

- 별빛지기의 청록 후드와 등불.
- 철문지기의 큰 방패와 밝은 갑옷.
- 사수의 흰 머리와 주황색 목도리.
- 파수꾼의 둥근 기계 몸체와 큰 손.
- 연금사의 보라색 버섯 모자.

이 실루엣과 색상은 역할을 구분하는 기반으로 사용할 수 있다.

### 전투용으로 정리할 것

- 옷의 잔주름, 작은 장식끈·버클, 촘촘한 명암 단계를 줄인다.
- 무기·손·몸통이 겹쳐 한 덩어리로 보이지 않도록 자세를 벌린다. 특히 사수는 활과 시위를 명확히 드러낸다.
- 같은 픽셀 단위와 외곽선 규칙으로 대기·이동·공격·피격 프레임을 제작한다.
- 상세 초상화와 작은 전투 스프라이트의 묘사량을 다르게 잡는다. 현재 컨셉의 매력은 초상화에도 남길 수 있다.
- 배경의 유적과 숲은 유지하되, 캐릭터가 싸우는 바닥의 잔무늬와 밝은 장식을 줄인다.

**권장 수준은 세부 묘사 정리다. 전면적인 캐릭터 교체나 무조건적인 저해상도화는 현재 증거로 필요하다고 판단하지 않는다.** 단순화 정도는 같은 공격 연출을 적용한 두 버전을 휴대폰 크기에서 비교해 결정한다.

## 6. 우리 게임의 전투 연출 제안

아래 내용은 원작의 정확한 수치를 재현한 것이 아니라, 우리 게임에서 검증할 제작 방향이다.

### 한 번의 명중을 구성하는 순서

1. 준비: 몸과 무기가 공격 방향 반대로 짧게 당겨진다.
2. 공격: 손·무기가 빠르게 앞으로 뻗고 궤적 또는 투사체가 보인다.
3. 명중: 적의 짧은 플래시, 피격 자세, 타격 이펙트, 피해 숫자, HP 변화, 소리가 같은 시점에 발생한다.
4. 회복: 공격자가 자세를 되찾고, 적의 색과 실루엣이 다시 보인다.
5. 처치: 마지막 타격이 읽힌 뒤 적이 사라지고 다음 대상으로 전환한다.

| 역할 | 동작과 효과 제안 |
| --- | --- |
| 철문지기 | 방패를 당겼다가 짧게 밀어내고, 접촉점에서 굵은 충격광과 먼지가 터진다 |
| 초승달 사수 | 활을 당기는 자세 → 가는 발사 궤적 → 적 위치의 작은 관통광으로 공격 방향을 보여준다 |
| 톱니 파수꾼 | 좌우 펀치에 서로 다른 동작을 주고 마지막 타격을 크게 강조한다 |
| 별빛지기 | 낮은 밝기의 보호막을 유지하고, 보호막이 깨지거나 반격할 때만 밝게 강조한다 |
| 이슬 연금사 | 투척 궤적과 바닥의 물방울 장판을 구분하고 지속 피해의 숫자는 묶어서 표시한다 |

일반 공격과 큰 스킬의 강조 정도를 구분한다. 강한 타격에는 짧은 멈춤과 약한 화면 흔들림을 시험하되, 평타마다 전역 정지를 넣지 않는다. 다수의 자동 공격이 동시에 발생하는 전투에서 흐름이 끊기거나 화면이 계속 흔들리지 않도록 한다.

## 7. 다음 제작의 합격 기준

캐릭터 수를 더 늘리기 전에 **근접 1명 + 원거리 1명 + 적 1종**으로 짧은 전투 시제품을 만든다.

- 어느 캐릭터가 누구를 때렸는지 별도 설명 없이 보인다.
- 체력 감소와 이펙트가 같은 명중에 연결된다.
- 일반 공격·강한 공격·처치가 서로 다른 강도로 느껴진다.
- 소리를 꺼도 명중이 보이고, 소리를 켜면 타격 리듬이 강화된다.
- 휴대폰 가로 화면에서 무기, 적의 실루엣, HP 표시가 이펙트 뒤에 오래 가려지지 않는다.
- 소규모 전투가 통과하면 아군 5명과 다수의 적으로 확대해 겹침과 프레임 성능을 확인한다.

이번 검토에서는 영상 캡처와 개선 방향을 기록했다. 캐릭터 이미지나 전투 구현을 변경한 결과물은 아니다.
