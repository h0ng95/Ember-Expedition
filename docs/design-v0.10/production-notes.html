v0.9에서 설계한 기본 6종, 분기 12종, 최종 6종, 결합체 6종을 실제 전투 데이터와 애니메이션으로 연결한다. 이번 결과는 전투 시험실에서 비교할 수 있는 첫 제작본이다. 출시용 수치와 모든 세부 동작을 확정한 버전은 아니다.

애니메이션 갤러리 · 전투 밸런스 보고서 · 독립 검증과 실기기 기록 · 이전 30형태 설계

1 게임에서 확인하는 방법

메인 화면의 CATALOG LAB / 30으로 들어간다. 형태를 선택하고 최대 다섯 명을 편성한 뒤 전장에서 위치를 옮긴다. 적 편성을 고르고 전투를 시작하면 이동, 기본 공격, 고유 기술, 보호막, 회복, 상태 효과를 시험할 수 있다. 일시정지와 배속, 재도전으로 같은 편성을 비교한다.

최종형은 원래 선택한 분기 기술을 유지한다. 시험실의 형태 추가 과정에서도 기본 → 분기 → 최종의 재료 소모, 또는 두 분기의 결합 규칙을 거친다. 시험실의 자유 편성은 실제 원정의 소환 운과 공급 제한을 재현하지 않는다.

ANIMATION QA에서는 형태별 대기·걷기·공격·피격·쓰러짐을 반복해서 확인한다. HTML 갤러리는 같은 원본 PNG와 프레임 좌표를 읽는다. 갤러리를 다른 컴퓨터로 옮길 때에는 HTML만 복사하지 말고 저장소의 이미지 상대 경로도 유지해야 한다.

2 전투 구현

Unity 화면과 자동 대전 검증이 동일한 CatalogBattle을 사용한다. 능력치는 unit-catalog-v010.json에 두고, v0.9의 초안 JSON은 비교 기준으로 보존한다.

항목 구현 내용
30형태 기본·분기·최종·결합의 능력치, 기술, 고유 특성
최종형 선택한 분기의 기술 + 최종 기술
전승 본래 특성과 별도 전승 특성, 성장 진행과 재료 소모
결합 두 분기 소모, 기준 동료의 전승 특성과 자리 유지
전투 계산 방어, 보호막, 화상, 둔화, 표식, 회복, 범위와 대상 수
시간 고정 간격 시뮬레이션, 배속·일시정지
적 방향 왼쪽 고정

소환·진행·유물·영구 해금이 포함된 한 원정 전체의 밸런스는 이 대전 실험만으로 결정하지 않는다. 측정 조건과 수치 변경의 근거는 별도 밸런스 보고서에 기록한다.

3 아트 파일과 재생 규격

30개 시트, 총 660프레임을 제작했다. 형태 하나에 6열 × 4행의 RGBA PNG 한 장을 사용한다. 24칸 중 마지막 두 칸은 비우고 22프레임을 배치한다. 전체 30개 시트의 프레임 누락·잘림 검사에서 발견된 문제는 수정 후 재검사를 통과했다.

행동 프레임 수 0부터 시작하는 인덱스
대기 4 0–3
피격 2 4–5
걷기 6 6–11
공격 6 12–17
쓰러짐 4 18–21

이미지 생성 도구로 각 형태의 포즈를 제작했다. 자동 생성 결과의 칸 간격이 정확히 같지 않아, 원본 픽셀을 바꾸지 않고 투명 영역을 검사해 실제 프레임 사각형과 발 위치를 art-manifest.json에 기록했다. 프레임마다 몸 크기를 자동으로 맞추면 움직이는 중 확대·축소되는 문제가 생기므로, 재생에서는 일정한 배율을 사용한다.

프레임이 서로 닿거나 잘리는 8개 시트는 이미지 생성 도구로 다시 수정했다. 약한 배경 잔광은 Unity에서 시트를 불러올 때 알파 컷오프 셰이더로 별도 렌더 텍스처에 제거해 표시한다. 원본 PNG와 정확한 생성·수정 프롬프트는 보존하며, 채택한 원본과 작업 폴더의 30개 PNG 해시가 모두 일치한다. HTML 갤러리는 원본 PNG를 보여 주므로 이 잔광이 약하게 보일 수 있다.

모바일에서는 Point 필터와 밉맵 없는 설정을 사용하며, 필요한 시트만 로드하고 사용하지 않는 시트는 해제한다. 원본 크기와 실제 임포트 해상도는 별개다.

전투에서는 준비 동작 0–2번 뒤에 실제 기본 공격·스킬 사건이 발생할 때 명중과 회복 포즈 3–5번을 한 번 재생한다. 시트 미리보기의 반복 재생과 전투의 명중 타이밍을 구분했다. 임시 보스는 기존 돌골렘 그림을 확대해 사용하며, 새로운 보스 애니메이션 22프레임을 제작한 것은 아니다.

파일 확인할 내용

프레임 개수와 잘림 검사가 통과해도 연속 재생의 부드러움이나 모든 동작의 완성도를 보장하지는 않는다. 동작 사이의 발 미끄러짐, 손·무기의 형태 일관성, 타격 순간의 읽기 쉬움은 화면에서 별도로 검토한다.

5 다음 제작에서 다듬을 부분

이번 22프레임은 각 형태의 공통 행동 묶음이다. 서로 다른 모든 스킬의 전용 동작, 최종형의 분기별 별도 공격, 적·보스의 새로운 애니메이션은 이 수에 포함하지 않는다. 이를 추가할 때에는 기존 기본 공격을 무조건 복제하지 말고 기술의 준비·명중·회복 시간을 구분한다.

걷기와 공격의 손발, 망토·깃발의 연속성은 첫 제작본을 기준으로 다듬는다. 전투의 최종 타격감은 캐릭터 포즈 외에도 명중 효과, 투사체, 효과음, 화면 반응을 실제 공격 사건에 맞추어 조정해야 한다.

기존 초기 시안의 비율과 색을 참고하고 직업마다 장비와 실루엣을 새로 구성했다. 다른 게임의 캐릭터를 추출하거나 덧칠하지 않았다. 공개 출시 전 이름·형태의 유사성 검토 기록은 별도로 남긴다.
