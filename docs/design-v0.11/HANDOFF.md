# 잔불 원정대 v0.11 · 본편 원정 연결

2026-10-19. 별점 지도 대신 새 원정·이어하기로 시작한다. 30형태 전투 시험실에서 검증한 동료 성장 규칙을 본편에 연결하는 작업이다.

## 이번 범위

- 홈 → 준비·소환·배치·성장 → 자동 전투 → 결과 → 다음 준비, 마지막 6번째 전투는 성문 골렘이다.
- 기본 동료는 기사·궁수·사제 3명. 첫 준비에 1회, 이후 다섯 준비에 각각 2회 소환해 총 공급은 14명이다. 12전투 설계를 6전투로 압축하면서 성장 재료량은 유지했다.
- 기본 6계열 균등 추첨, 빈 결과 없음. 같은 계열이 3번 연속 나오면 다음 소환에서 그 계열을 제외한다. 소환 결과와 난수 상태를 함께 저장한다.
- 출전 최대 5명, 대기석과 드래그 배치. 출전 인원이 꽉 차면 대기 동료를 출전 동료 위로 놓아 교체한다.
- 전승·분기 진화·최종 진화·6종 결합은 기존 CatalogRoster 규칙을 사용한다. 재료 소모를 확인하고 실행한다. 준비 중 되돌리기는 이미 뽑은 동료와 사용한 소환권을 바꾸지 않는다.
- 일반 패배는 등불 1 소모, 등불 0 또는 최종 보스 패배 시 종료. 다음 전투는 동료 전원 복귀·HP 회복·전투 상태 초기화. 성장과 편성은 유지한다.
- 소환·성장·배치·전투 시작·결과를 v0.11 전용 저장 키로 보관한다. 전투 중 종료·거점 이동 후 이어하기는 같은 시작 상태에서 재생한다. 저장 오류는 안내하고 새 원정 교체를 확인한다.
- 본편 전투는 넓은 화면에서 아군의 30형태 애니메이션을 재생한다. 적은 기존 야수·약탈자·골렘 이미지로 구별한다. 골렘은 크게 표시하고 적은 왼쪽을 향한다.

기존 지도·별점·스테이지 코드는 기본 실행에서 제외하고 이력으로 보존했다. 30형태 전투 시험실은 홈의 작은 개발 메뉴에서 연다.

## 확인된 자동 검사

- 순수 C# 원정 상태·소환·성장·저장: 2,267 assertions 통과.
- 기존 카탈로그 기본 검사 110, 독립 검사 109, 기존 전투·스테이지 검사 326 assertions 통과.
- Unity JsonUtility 실제 저장 왕복 및 전투 재개·진행: 614 assertions 통과.
- 8개 시드의 간단한 자동 성장 편성이 6전투 원정을 모두 완주했다. 초반 연결 확인을 위한 낮은 난도이며 출시 밸런스 검증 결과로 해석하지 않는다.

## Android · Buddy2 확인

첫 v0.11 Android 빌드와 Galaxy Buddy2 설치에 성공했다. 휴대폰에서 다음 항목을 직접 조작해 확인했다.

- 별점 지도 대신 새 원정·이어하기 홈으로 시작하고 한글이 표시된다.
- 한 번 소환하면 대기석에 동료 한 명이 추가되고 소환 횟수가 1에서 0으로 줄어든다.
- 앱 프로세스를 종료하고 다시 실행해 이어하기 했을 때, 저장된 원정 JSON과 소환 결과가 그대로 유지됐다.
- 동료 상세창을 연 상태에서 뒤쪽 전투 시작 버튼을 눌러도 실행되지 않는다.
- 대기 동료 전승으로 기사 성장 0→1, 재료 동료 소모를 확인했다. 되돌리기는 성장 1→0과 재료 동료를 복구하며 사용한 소환권은 0을 유지했다.
- 대기 동료를 전장으로 드래그해 출전 3→4명을 만들고 첫 전투·일시정지·승리·다음 준비를 확인했다.
- 화면 검토에서 발견한 거점 글꼴 기호, 재료 목록의 출전/대기 구별, 거점 복귀 동작을 수정했다.
- 사용자 피드백에 따라 준비와 본편 전투의 발 위치 기준을 아래로 옮겼다. 준비 드래그의 좌표 계산도 같은 기준으로 변경했다. 기존 저장의 세로 배치 범위가 한 줄로 눌리지 않도록 화면에 맞추며, 동료의 저장 좌표를 초기화하거나 덮어쓰지 않는다.

최종 수정 APK는 2026-10-19 Galaxy Buddy2에 기존 저장을 유지하는 업데이트 설치(`adb install -r`)와 앱 실행을 완료했다. 최종 빌드에서도 Unity 검사 614 assertions와 8/8 시드 완주를 통과했다. APK SHA-256: `5D55686F6F841339729F8339A60FC4F7674919789D8D243A33BAB9591221FAA9`.

첫 검증 사진과 저장 표본은 `device-evidence/`에 보관한다. 마지막 배치 범위 보정 후 추가 터치 검사는 생략하고 사용자 요청에 따라 작업을 마감했다. 장시간 성능·모든 성장 조합의 휴대폰 터치 검사는 이번 결과에 포함하지 않는다.
