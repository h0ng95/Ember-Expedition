하나의 숲에서 나온 적들

짙은 나무껍질, 이끼, 상아빛 뿔과 작은 호박색 눈을 공유한다. 졸개의 짧은 목깃은 정예의 어깨로, 보스의 커다란 갈기로 이어진다. 아군의 금속 갑옷과 천옷과는 재질부터 구분한다.

크기 기준은 1280 화면 좌표에서 아군 높이 144, 졸개 78, 원거리 112, 정예 138, 보스 244다. 정예는 키보다 앞쪽 어깨와 긴 뿔의 폭으로 위협을 준다. 수치는 미리보기 제안이며 현재 APK에는 반영되지 않았다.

다음은 움직임

  • 뿔짐승: 짧은 발걸음 → 머리를 낮추고 들이받기.
  • 가시등: 등을 웅크리기 → 가시가 솟음 → 전방으로 발사.
  • 돌격 정예: 앞발 고정 → 낮은 돌진 자세 → 빠른 전진.
  • 우두머리: 무거운 숨 → 갈기와 앞발을 낮춘 예고 → 돌진·광폭화.
