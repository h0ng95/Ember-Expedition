# 캐릭터 제작 방식 비교 · 현재 생성 방식과 SPUM

2026-11-01 · 공식 상품 설명·위키·상품 갤러리와 현재 프로젝트 코드 기준

**결정: 사용자가 SPUM을 도입하지 않고 현재 제작 방식을 유지하기로 했다.** 아래는 그 결정 전에 검토한 장단점 기록이다. SPUM 구매·임포트·런타임 성능 실험은 하지 않았으며, 3종 비교 실험도 현재 진행 계획에 넣지 않는다. 기존 그림체와 장비·모션의 일관성을 계속 검수한다.

## 공식 자료에서 확인한 기능

- 상품 표시 가격은 세금 전 US$39.99, 버전 1.8.9다. Unity LTS 2022·6000+ 및 Android 등이 명시되어 있다. 제작사의 지원 표기이며, 우리 Unity 6000.3.24f1/Buddy2 프로젝트에서 직접 검증한 것은 아니다. [상품 페이지](https://assetstore.unity.com/packages/2d/characters/2d-pixel-unit-maker-spum-188715)
- 머리·옷·갑옷·좌우 무기를 조합한다. 대기·달리기·사망·기절·검 공격·활 공격·마법 공격의 7가지 종류를 안내한다. 에디터의 캐릭터 제작 기능과 게임에서 만든 캐릭터를 재생하는 기능은 구분해야 한다. 소환·결합·능력치·전투 규칙을 제공하는 게임 시스템은 아니다. [상품 설명](https://assetstore.unity.com/packages/2d/characters/2d-pixel-unit-maker-spum-188715), [외형·애니메이션 설명](https://github.com/soonsoon2/SPUM/wiki/How-to-use-SPUM)
- Prefab 및 스프라이트 시트·GIF 내보내기를 설명한다. 프레임 속도와 출력 크기 등을 설정한다. 내보내기 도구는 문서상 Beta 경로이며, 최신 유료 버전에서 우리가 필요한 출력이 정상인지 별도로 확인해야 한다. [내보내기 문서](https://github.com/soonsoon2/SPUM/wiki/Export-SPUM-characters)
- 1.7 문서는 애니메이션 상태·프리셋과 사용자 클립을 설명하고, 1.8 문서는 종족·직업·장비 등급·속성 필터를 설명한다. 필터에 있는 항목이 기본 상품에 필요한 모든 리소스를 포함한다는 뜻은 아니다. 추가 팩과 기본 상품을 구분한다. [1.7 문서](https://github.com/soonsoon2/SPUM/wiki/SPUM-170-version-introducing-English-version), [1.8 문서](https://github.com/soonsoon2/SPUM/wiki/180-version-%E2%80%90-SPUM-CG)

## 우리 프로젝트에서의 판단

아래 비교는 제작 구조와 실제 공식 갤러리를 보고 내린 판단이다. SPUM으로 우리 캐릭터를 제작한 결과나 성능 측정치는 아니다.

| 기준 | 현재 전신 시트 생성 | SPUM 중심 제작 |
| --- | --- | --- |
| 현재 방패 기사의 외형 유지 | 직접 참조하므로 유리. 그래도 생성마다 차이가 발생 | 기본 파츠만으로 동일한 외형을 얻기는 어려움. 전용 파츠 제작 필요 |
| 무기·손·방패의 일관성 | 프레임마다 바뀌거나 늘어나는 오류를 검수해야 함 | 고정한 파츠를 재사용하므로 원칙적으로 유리. 손 연결·가림·무기 궤적 검수는 필요 |
| 직업과 진화체 수량 확대 | 각 시트의 포즈·크기·알파를 반복 검수 | 공통 모션과 장비 변형을 재사용하기 쉬움. 조합체의 개성은 별도 디자인 필요 |
| 공격 동작의 수정 | 해당 그림을 다시 만들고 기존 프레임과 맞춰야 함 | 클립과 파츠 구조를 수정·재사용할 수 있음. 원하는 타격감이 자동 완성되지는 않음 |
| 그림체 | 지금의 비교적 묵직한 갑주와 명암 유지 가능 | 공식 갤러리 기본 리소스는 더 단순한 도트, 큰 머리 비율. 배경·적과 다시 비교 필요 |
| 특수 보스 | 용·큰 야수·부유 갑주 등 자유롭게 설계 | 공개된 기본 기능만으로 우리 보스를 그대로 대체할 수 있다는 근거 없음 |
| 도입 비용 | 구매비보다 반복 생성·수정·검수 시간 | 구매비 외에 30형태 재구성, 임포트·크기·타격 시점 연결과 검수 시간 |
| 모바일 성능 | 현재 시트 표시를 사용 | 시트 출력 또는 Prefab 선택에 따라 달라짐. 우열은 Buddy2 실측 전 단정 불가 |

**기존 작업이 아깝다는 이유로 현 방식을 고집할 필요는 없다. 반대로 SPUM이 많은 문제를 해결한다는 이유만으로 게임 전체의 그림체를 바꾸는 것도 이르다.** 사용자가 가장 강조한 아트 일관성과 실제 전장의 동작을 함께 평가한다.

## 추후 결정을 바꾸는 경우에만 참고할 실험

1. 현재 기본 기사·궁수·마법사를 비교 대상으로 고정한다. 전투 수치와 공격 간격은 바꾸지 않는다.
2. SPUM의 제한된 체험 또는 정식 라이선스로 별도 실험 프로젝트에서 3종을 만든다. 무료 버전은 오래된 1.0.2라 최신 유료 기능 평가를 대신할 수 없다.
3. 첫 연결은 스프라이트 시트 내보내기를 검토한다. 현재 `CatalogArtView`와 전투 렌더러는 시트·프레임·몸 기준 크기 데이터를 사용하므로, Prefab/Animator를 즉시 전면 도입하는 것보다 변화 범위를 줄일 수 있다. 내보낸 셀·피벗·공격 접촉 시점을 현재 규약에 맞춰 연결해야 한다.
4. 같은 배경, 같은 사람 높이, 1×·2×에서 걷기·검·활·마법·쓰러짐을 비교한다. 무기 수·손 위치·발 접지·타격 시점·아군 간 구분을 확인한다. 화면에서 더 어울리는지를 먼저 평가하고 Buddy2 성능을 측정한다.
5. 채택한다면 아군 전체의 표현 규칙을 정하고 순차 전환한다. 기존 보스·소품의 팔레트·윤곽도 그 기준에 맞춰 조정한다. SPUM 일부와 현재 스타일 일부를 검토 없이 섞지 않는다.

현재 화풍을 최종적으로 유지한다면, 장기적으로는 고정된 원화·장비 파츠와 수작업으로 정돈한 동작을 기반으로 제작하고 생성 도구는 디자인 탐색·초안·보스와 연출 원화에 활용하는 방향을 권한다. 이것은 추가 제작 공정이며, 현재 시트를 자동으로 완전한 리깅 캐릭터로 바꿔준다는 뜻이 아니다.

## 상업 출시와 자료 범위

공식 한국어 위키는 유료 리소스의 Unity 게임 상업 이용을 안내하고, 무료 버전은 학습·테스트 용도로 설명한다. 오래된 GitHub README의 무료 상업 사용 문구와 서로 다르므로 무료판을 출시용으로 간주하지 않는다. 출시에는 구입한 패키지의 실제 적용 라이선스를 확인하고 필요한 정식 라이선스를 사용한다. [공식 라이선스 안내](https://github.com/soonsoon2/SPUM/wiki/Introducing-SPUM%E2%80%90ko%E2%80%90KR)

정식 에셋의 사용 권한을 얻는 것과 우리만 사용하는 독점 디자인을 얻는 것은 다르다. 독자적인 인상이 필요하면 색 변경뿐 아니라 주요 장비·실루엣을 직접 설계한다. 생성 이미지 역시 다른 작품과의 유사성 검수를 계속한다.

상품 페이지와 위키는 업데이트 시점이 다르다. 이 문서는 설치·테스트를 마쳤다는 보고서가 아니라, 확인한 기능과 프로젝트 적합성을 구분한 도입 검토다.
