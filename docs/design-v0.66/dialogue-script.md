# v0.66 · 현재 보스 대사

2026-11-01 · 시즌1 스포일러 · 실제 한국어 런타임과 대조한 대본. 고정 초상화가 아닌 생존한 출전 동료가 말한다. 영어 런타임 번역은 별도 후속 작업이다.

## 5전투 · 숲

1. 작은 녀석이 나왔어. 쓰러진 잿갈기 곁을 떠나지 않네.
2. 무기를 내려. 더 공격할 필요는 없어.
3. 봐. 이그니스 주변에만 새싹이 자라고 있어.
4. 이 빛과 새끼를 지키던 걸까. 숲에서 본 일은 기록해 두자.

## 10전투 · 성채

1. 골렘 안에서 명령판이 나왔어. 왕실 문장이 찍혀 있어.
2. ‘이그니스에 접근하는 자는 누구든 막아라.’ 우리도 공격한 이유가 이거였네.
3. 사람보다 이그니스를 먼저 지키라는 명령이군.
4. 뒷면에 폐광의 보관소 이름이 있어. 그곳의 장부를 찾아보자.

## 15전투 · 폐광

1. 이 장부에 숲과 성당의 이그니스를 왕궁으로 옮긴 기록이 있어.
2. 왕국의 동력을 다른 땅에서 가져온 거였군.
3. 그 뒤에 물이 마르고 생물이 변했다는 보고도 붙어 있어. 관계가 있는 걸까?
4. 장부를 챙겨. 서리 성당에 남은 기록과 비교해 보자.

## 20전투 · 서리 성당

1. 드러난 제단을 봐. 이그니스와 같은 눈꽃 문양이 새겨져 있어.
2. 왕국이 세워지기 전부터 이 빛이 성당을 지켰다는 기록도 있어.
3. 처음부터 왕국의 물건은 아니었던 거군.
4. 이그니스는 여기 두자. 정원의 기록까지 확인하고 왕궁에 보고한다.

## 25전투 · 황혼 정원

1. 이 왕실 도면에 적혀 있어. 이그니스를 옮겨 정원의 힘을 왕궁으로 빼내던 장치야.
2. 옛 왕실이 먼저 빼앗았고, 수호자들은 자기 것을 되찾았던 거군.
3. 그럼 이그니스는 돌려줘야겠네. 하지만 왕국의 난방과 결계는 어떻게 해?
4. 정원의 빛은 두고 간다. 왕궁의 추출을 멈춘 뒤, 남은 동력으로 사람들을 지킬 방법을 찾자.

## 30전투 · 잿빛 왕궁

1. 왕관이 부서지자 용이 공격을 멈췄다. 저 장치에 묶여 있었던 거야.
2. 왕궁으로 흐르던 빛도 끊겼어. 이그니스가 용 곁에 남아 있어.
3. 우리가 가져온 이그니스도 고향으로 돌려보내자.
4. 돌아가면 남은 동력을 난방과 결계부터 쓰자. 사람들을 지킬 다른 방법도 찾아야 해.
