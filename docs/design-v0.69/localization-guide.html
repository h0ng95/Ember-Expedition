한국어·영어 현지화 기준

2026-11-02 · IGNIS: ASHEN OATH · v0.69

첫 출시 언어는 한국어와 영어다. 다른 나라에서 실행해도 영어로 게임의 선택과 이야기를 이해할 수 있도록 한다. 제3언어는 출시 후 실제 이용자와 번역 검수 여건을 보고 추가한다.

언어 선택

  • 별도 선택이 없으면 기기 언어가 한국어일 때 한국어, 그 외에는 영어.
  • 설정의 Language · 언어에서 한국어 / English 선택. 선택 즉시 화면에 반영하고 적용하고 닫기 / Apply and close로 저장한다.
  • 설정 초기화는 음량·접근성 옵션과 함께 언어를 기기 기준 자동 선택으로 돌린다.
  • 언어는 원정 저장과 독립된 기기 설정이다. 동료, 골드, 연구, 난수, 점수, 이야기 해금, 재도전 기회는 언어 전환으로 바뀌지 않는다.
  • 이전 설정 파일에 언어 필드가 없어도 기존 음량·흔들림·번쩍임 옵션을 유지하고 자동 선택을 적용한다.

유닛 전체 이름은 정보·진화·결합 화면에서 확인한다. 긴 이름을 좁은 HUD에 무리하게 우겨 넣지 않고, 필요할 때만 짧은 표시명을 별도로 둔다.

대사와 문장

  • 대사는 번역 문장 자체가 자연스러운 대화여야 한다. 한국어 어순을 보존하기 위한 조각 번역을 새 기능에 추가하지 않는다.
  • 수치가 들어가는 새 문장은 {0}, {1} 같은 자리표시자가 있는 문장 전체를 번역 키로 만든다. 두 언어의 자리표시자는 일치해야 한다.
  • 반전은 5개 지역의 발견 순서대로 유지한다. 초반 대사에서 왕실의 약탈이나 수호자의 정체를 미리 확정하지 않는다.
  • 새로운 시나리오·직업·연구를 만들 때 한국어와 영어를 같이 작성한다. 영어가 비어 있으면 생성 검증에 실패하도록 한다.

파일과 작업 방법

  • 편집 원본: messages.json. 항목마다 안정적인 키, 한국어, 영어, 사용 위치를 둔다. 기존 키는 번호를 다시 매기지 않는다.
  • 생성 도구: build.cjs. node tools/localization/build.cjs로 런타임 표를 갱신한다.
  • 생성 결과: CatalogText.Data.cs. 직접 고치지 않는다. Unity와 헤드리스 테스트가 같은 표를 사용한다.
  • node tools/localization/build.cjs --check는 빠진 번역·중복 키·자리표시자 불일치·생성 결과 불일치를 검사한다.
  • 현지화 테스트는 정적 데이터의 언어 전환과 저장·소환·전투의 독립성을 확인한다.

현재 표에는 기존 UI에서 가져온 문장 조각도 일부 있다. 이를 새 문구의 작성 방식으로 확장하지 않는다. 어순이 달라지는 문구는 문장 전체 키로 전환한다. 개발 시험실의 내부 코드명·기술 ID와 테스트용 로그는 플레이어 번역 범위에 포함하지 않는다.

해외 공개 전 남은 검수

영문 UI 제공과 영어권 사용성 검증은 별개다. 영어 사용자에게 첫 소환, 성장, 첫 진화, 결합 손익, 연구의 지역 조건, 패배 후 재도전을 설명 없이 수행하게 하고 막힌 지점을 기록한다. 특히 Fusion을 필수 진행 단계로 오해하는지 확인한다.

이야기와 고유명은 영어 모국어 검수를 한 차례 더 거친다. 앱 마켓 소개·개인정보 안내·광고 SDK 동의 화면은 실제 출시 구성이 정해진 뒤 별도로 현지화한다. 이번 작업으로 다른 언어 번역이나 마켓 등록까지 완료되는 것은 아니다.
