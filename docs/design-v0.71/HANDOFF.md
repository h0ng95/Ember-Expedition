## 화면에 계속 뜨던 + / − 숫자

`+`는 회복량, `−`는 피해량, `◇`는 보호막 수치였다. 일반 공격, 화상·독 틱, 범위 회복과 보호막이 동료마다 반복되어 전장을 가렸다.

| 항목 | 변경 |
| --- | --- |
| 일반 공격·화상·독 피해 | 떠오르는 숫자 숨김. 타격 이펙트·체력바·상태 아이콘으로 확인. |
| 스킬 피해 | 같은 대상의 0.55초 이내 피해를 하나로 합산. 대상별 숫자는 한 개씩 유지. |
| 회복 | 기본은 녹색 효과와 체력바. 회복 전 체력이 40% 미만이고 한 번에 최대 체력의 8% 이상 회복하면 숫자 표시·합산. |
| 보호막 | 반복 숫자 숨김. 보호막 바와 실제 흡수 시 방패 효과는 유지. |
| 빙결·중독 | 상태 문구는 유지. 동일 대상 재표시 간격은 빙결 2초, 중독 3초. |
| 화면 전체 | 떠오르는 문구 최대 24개 → 8개. 숫자보다 상태 알림 우선. |

이 제한은 전투 기록이나 실제 피해·회복량을 줄이지 않는다. 아군 체력은 왼쪽 목록에서도 계속 볼 수 있다. 목록의 공격 활동 색 띠는 제거된 상태다.

## 공격 효과

- 방패 기사 계열의 검, 수호 기사의 방패 밀치기, 광휘 성기사의 망치를 구분한다. 창·군기의 찌르기에 검 궤적을 붙이지 않는다.
- 화살은 화살촉·깃털, 화염탄은 화구·불티, 얼음탄은 회청색 결정으로 구분한다. 성직자는 금빛 성광, 정원 적은 녹색 독성탄이다.
- 폐광 투석병은 궁수와 같은 Raider AI를 쓰지만, 무기는 돌이므로 투사체를 별도 분류했다.
- 실제 `Damage` 이벤트에서 접촉 효과를 시작한다. 피해가 없는 지원 스킬이나 공격 시작 알림에 가짜 검 타격을 만들지 않는다. 지속 피해에는 작은 기존 표시만 사용한다.
- 투사체의 꼬리는 실제로 이동한 거리만큼만 그린다. 좌향·대각선 회전과 모션 줄이기를 지원한다.
- 보스는 기존 뿌리·얼음·불기둥·브레스 시트를 유지한다. 보강 입자는 실제 코어의 목표 좌표와 반경을 사용한다.

16개 신규 시트는 각각 8프레임이다. PNG 합계 70,640바이트, 비압축 RGBA 약 2.89 MiB다. Point/Clamp/비압축/밉맵 없음, 투명 2픽셀 경계이며 캐시한 텍스처 UV로 그린다. 효과 기록 최대 24개와 게임 시간 기반 재생을 유지한다. 별도 파티클 오브젝트나 텍스처를 매번 만들지 않는다.

## 검증

- Unity: 신규 128프레임의 크기·투명 경계·임포트, 30형태 무기 분류, 접촉·보호막·지속 피해 분리, 일시정지와 기록 상한 검사 통과.
- 숫자 정리: 일반/지속 피해 억제, 스킬·회복 합계 보존, 낮은 체력 회복, 상태 알림 우선, 최대 8개 검사 통과.
- 기존 회귀: 30형태 × 1×/2× × 30/60fps = 120개 공격 타이밍 사례, 보스 피격/지속 피해/시체 표시 검사 통과.
- 최종 Android IL2CPP 개발 APK를 Galaxy Buddy2에 설치했다. 보스 6종 및 섬광·모션 줄이기 반복을 포함한 7개 사례가 완료됐다. 각 사례에서 시뮬레이션 18초를 진행했고 1×와 2×를 모두 확인했다.
- 실제 동시 문구 최고치는 숲·폐광·용광로 3개, 서리·정원 7개, 왕궁 6개, 저자극 숲 반복 3개였다. 일반 공격·지속 피해 수치는 사라지고 스킬 피해·상태 알림이 남는 장면을 캡처로 확인했다.
- 테스트 전 저장 파일과 PlayerPrefs를 백업하고 종료 후 바이트 단위로 복원 확인했다. QA 편성은 동작을 오래 관찰하도록 체력을 높였으므로 난이도나 출시 성능의 증거로 쓰지 않는다. 녹화·ReadPixels가 포함되어 정식 프레임 성능 측정으로 해석하지 않는다.

## 출처와 재현

[PixelFX](https://github.com/patch-gg/pixelfx) `a84159688af3ca37a4be05a0d422b94451b2e24e`의 화살·화구·얼음 창·둔기 효과를 조정하고, 나머지는 해당 Painter로 작성했다. MIT 라이선스와 고지는 런타임 에셋 폴더에 포함하며 갤러리 폰트는 포함하지 않는다.

- 생성: `tools/pixelfx/generate-combat.mjs`
- 검증/빌드: `Expedition.EditorTools.CombatSpriteEffectsValidation.ValidateAndBuild`
- 일회성 개발 기기 검사: `combat-effects-audit.flag`. 임시 전투만 실행하며 원정·설정을 저장하지 않는다.
- APK: `unity/Builds/Android/expedition-combat-prototype.apk`
