01 준비 — 다음 행동을 바로 찾기

진행과 등불은 위에, 대기 동료와 소환·전투 시작은 아래에 둡니다. 기사를 누르면 상세 정보가 열립니다. 성장 버튼은 이 상세창에서만 보여 주고, 적의 주요 행동은 시작 전에 확인합니다.

01 / SUMMON

한 번 누르고, 나온 동료로 판단

후보를 여러 명 읽는 단계 없이 한 동료가 합류합니다. 작은 결과 안내와 대기석 강조만으로 다음 배치나 전승으로 이어갑니다.

02 / COMBAT

전투가 시작되면 전장을 비우기

준비용 패널을 접고 캐릭터와 명중, 보스의 행동에 집중합니다. 배속과 정지 위치만 남깁니다. 전투 탭은 명중 순간의 배치 예시입니다.

03 / ART

타격감은 동작과 소리로 완성

걷기, 공격 준비, 휘두르기, 명중, 피격을 연결해야 합니다. 이 정적 시안만으로 실제 타격감이나 기기 성능을 검증했다고 보지 않습니다.

전체 기획 읽기 · 노션용 원문

문서용 화면 시안 · 탭·소환·전투 시작 버튼은 예시 화면을 전환합니다. 소환 결과는 설명을 위한 고정 예시이며, 전투 계산·드래그 배치·전승은 구현하지 않았습니다. 실제 소환은 무작위로 설계합니다.

보스는 기존 자동인형 이미지를 확대한 임시 표현입니다. 최종 보스 외형·배경·공격 모션은 별도 제작합니다. 수치·편성·터치 크기는 게임과 실기기에서 다시 검증합니다.
