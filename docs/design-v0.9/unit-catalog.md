# 잔불 원정대 직업·진화·결합체 상세 설계

2026년 10월 19일 · v0.9 콘텐츠 설계 초안 · v0.8의 전투·성장 상세 보완

**기본 6종, 분기 진화 12종, 최종 진화 6종, 특수 결합체 6종으로 총 30형태를 설계한다.** 각 형태의 능력치, 기술, 성장 조건, 전승 특성, 외형과 전투 역할을 함께 정의한다. 이 문서는 제작에 필요한 초안이며 밸런스 검증이나 아트 제작을 완료했다는 의미가 아니다.

사용자가 선택한 버튼 무작위 소환과 중세풍 도트, 가로 화면, 자동 전투와 사전 배치를 따른다. 여기서 결합체는 **서로 다른 계열의 분기 진화 동료 둘을 합쳐 얻는 별도 직업**이라는 제안이다. 숫자와 결합식, 이름은 검증 후 변경할 수 있다.

## 2 능력치의 의미와 공통 전투 규칙

### 수치의 단위

| 수치 | 뜻 | 비교할 때 주의할 점 |
| --- | --- | --- |
| HP | 최대 체력 | 전투가 끝나면 다음 준비에서 전원 회복하는 v0.8 제안 유지 |
| 위력 | 기본 공격과 기술 계수에 쓰는 공통 수치 | 회복·보호막도 별도 계수로 계산 |
| 방어 | 모든 피해에 적용하는 완화 수치 | 처음에는 물리·마법 방어를 분리하지 않음 |
| 공격 간격 | 기본 공격 한 번에 걸리는 게임 시간, 초 | 짧을수록 자주 공격. 스킬 재사용 시간과 별개 |
| 사거리 | 공격할 수 있는 중심 간 거리 | 1.0을 작은 배치 칸 한 개 폭으로 삼는 설계 단위 |
| 이동 속도 | 초당 이동하는 같은 거리 단위 | 실제 Unity 좌표와 화면 크기는 구현 때 대응 |
| 치명타·회피 | 기본값 0 | 초반에는 공격 결과를 읽기 쉽게 하고, 확률 효과는 후속 콘텐츠로 검토 |

**최종 피해 = 위력 × 기술 계수 × 피해 보정 × 100 ÷ (100 + 방어).** 방어 25는 피해 20% 감소, 방어 50은 약 33.3% 감소다. 모든 피해는 먼저 보호막에 적용하고 남은 양을 HP에 적용한다. 계산은 소수로 유지하고 화면 숫자만 반올림한다. 피해가 양수인 경우 표시를 위해 실제 피해를 정수 1로 올려 주지는 않는다.

기본 공격은 표에 적힌 위력의 100%를 한 대상에게 준다. 기사·기수는 근접, 궁수는 화살, 마법사·사제는 마법 투사체를 쓴다. 특수 결합의 공격 형태는 8장에서 따로 지정한다. 무기 타입은 초기 피해 공식에서 방어를 우회하지 않는다.

위력 증가는 기본 위력에 합산하고, 같은 종류의 공격 간격 감소는 합산 후 최대 40%까지 적용한다. 피해 증가도 같은 종류끼리 합산하며, 초기 콘텐츠의 총 증가 상한은 100%로 둔다. 여러 피해 감소 효과는 감소율을 곱해 계산하고 방어 외 감소는 총 50%까지만 적용한다. 이 상한은 과도한 중첩을 막는 첫 시험값이다.

### 자동 전투와 시간

기본 공격 대상은 가장 가까운 살아 있는 적이다. 원거리 동료는 사거리 안에 표식이 있는 적을 우선한다. 표식이 여럿이면 가까운 적, 거리도 같으면 생성 순서로 결정한다. 공격 준비가 시작된 뒤에는 대상이 죽거나 유효하지 않게 된 경우에만 다시 찾는다.

고유 스킬은 아래 표에 별도 조건이 없으면 **전투 시작 2초 후부터 사용 가능**하다. 유효 대상이 있고 재사용 시간이 끝나면 자동으로 사용한다. 공격 중에는 현재 타격을 마친 뒤 스킬을 사용하고, 스킬 사용 중 기본 공격은 진행하지 않는다. 기본 공격 재사용 시간은 스킬 때문에 초기화하지 않는다. 회복할 대상이 없으면 회복 스킬을 보류한다.

주기형 스킬은 전투 시작 2초 이후 첫 유효 순간에 발동한다. 조건형 스킬은 해당 조건이 발생할 때만 발동한다. 모든 재사용 시간은 1배속 게임 시간이며 2배속은 이동·피해·지속 시간·재사용 시간을 함께 두 배 빠르게 진행한다. 일시정지에서는 모든 전투 시간이 멈춘다. 별도 규칙이 없는 공격의 타격 시점은 준비 동작 0.25초 후를 임시값으로 사용하고 최종 애니메이션에 맞춰 조정한다.

### 상태 효과와 겹침

| 상태 | 공통 규칙 |
| --- | --- |
| 보호막 | 여러 보호막 수치를 합산하지 않음. 남은 양보다 큰 보호막으로 교체하며, 교체할 때 새 지속 시간을 사용 |
| 보호막 파괴 | 피해로 보호막이 0이 됐을 때만 발생. 만료·교체·전투 초기화는 파괴로 취급하지 않음 |
| 화상 | 해당 시전자 위력의 15% 피해를 초당 한 번, 3초 동안. 같은 대상에는 가장 강한 화상 하나만 적용 |
| 화상 갱신 | 더 강하거나 같은 화상은 위력·지속 시간을 갱신. 약한 화상은 무시. 틱은 적용 뒤 1·2·3초에 발생 |
| 둔화 | 이동 속도만 감소. 가장 큰 둔화 하나 적용, 최대 40%. 보스는 최종 둔화율의 절반 적용 |
| 표식 | 기본 지속 4초. 별도 계수가 없으면 자체 추가 피해는 없고 표적 선택에 사용 |
| 범위와 대상 수 | 원형은 중심 반경, 전방은 시전 방향의 부채꼴. 표의 최대 대상 수 적용 |
| 추가 피해 | 기본 공격 명중으로 취급하지 않음. 추가 피해가 같은 추가 피해를 다시 발생시키지 않음 |
| 회복 | 쓰러지지 않은 아군의 HP만 최대 HP까지 복구. 초과 회복은 보호막으로 바뀌지 않음 |
| 동률 선택 | 거리, 이후 생성 순서로 결정. 매번 임의로 재추첨하지 않음 |

보호막·회복의 기본 대상 선택에서 자신도 아군으로 센다. ‘다른 아군’이라고 적힌 효과만 자신을 제외한다. HP 비율이 낮은 순으로 대상을 선택하고, 보호막은 남은 보호막이 대상 최대 HP의 20% 이상인 동료를 우선순위에서 뒤로 보낸다. 새로운 보호막이 더 약하면 기존 보호막을 유지한다.

피해 사건은 피해 감소 → 보호막 소모 → HP 소모 → 사망 확정 → 생존자의 보호막 파괴·HP 조건 처리 순으로 계산한다. 쓰러진 동료는 반격이나 위기 보호막을 새로 발동하지 않는다. 피해를 받아 보호막이 깨지고 HP가 절반 이하가 된 동료는 반격과 위기 보호막 조건을 각각 확인한다. 새 보호막 지급이 이미 발생한 파괴 사건을 취소하지 않는다.

## 4 성장과 결합의 규칙

| 경로 | 필요한 것 | 남는 결과 |
| --- | --- | --- |
| 기본 → 분기 진화 | 받는 기본 동료 1명에 재료 동료 2명 전승 | 해당 계열 두 분기 중 선택한 1명 |
| 분기 → 최종 진화 | 분기 진화 후 추가 재료 동료 4명 전승 | 해당 계열 최종 형태 1명 |
| 특수 결합 | 결합식에 맞는 서로 다른 계열의 분기 진화 동료 2명 | 새 결합 직업 1명 |
| 일반 특성 전승 | 주는 동료 1명 소모 | 받는 동료의 성장 진행 +1과 특성 유지 또는 교체 |

재료 계열에 따라 일반 성장 진행량은 바뀌지 않는다. 최종 진화에는 이번 상세안에서 추가 아이템이나 처치 조건을 붙이지 않는다. v0.8에서 남겨 둔 유닛별 조건은 후속 검토 사항으로 돌린다.

**기본 진화는 고유 스킬을 분기 스킬로 교체한다. 최종 진화는 선택했던 분기 스킬을 유지하고 최종 스킬을 추가한다.** 본래 특성과 전승 특성은 계속 유지한다. 각 계열 최종 외형은 하나지만 분기의 공격 행동과 효과는 남는다. 최종 형태의 두 스킬이 동시에 준비되면 최종 스킬을 먼저 쓰고 분기 스킬은 이후 사용한다.

특수 결합은 전승 상세창의 별도 행동으로 제안한다. 두 동료를 고르면 일반 전승 결과와 결합 결과를 비교할 수 있다. 결합할 때 둘은 모두 원정 명단에서 사라지고 결과 1명이 생긴다. 플레이어가 지정한 **기준 동료의 배치 위치와 전승 특성 하나**만 유지하고, 본래 특성과 고유 스킬은 새 직업의 것으로 교체한다. 다른 동료의 전승 특성, 기존 진화 진행, 두 원본의 고유 스킬은 가져오지 않는다.

결합 재료는 분기 진화 상태만 허용하며 해당 계열의 어느 분기도 쓸 수 있다. 추가 성장 진행이 있는 분기를 재료로 쓰면 그 진행은 소멸하므로 미리 표시한다. 최종형·결합형은 결합 재료로 사용할 수 없고 결합형의 추가 진화도 없다. 최종형·결합형도 전승 특성 교체는 가능하지만 성장 진행은 더 받지 않는다.

일반 전승에서는 최종형·결합형도 재료로 사용할 수 있고 진행량은 1로 같다. 이때 보내는 동료의 실제 형태와 포기할 성장량을 명확히 보여준다. 성장할 여지가 없고 특성도 바뀌지 않는 전승은 확정할 수 없다. 현재 준비에서의 전승·진화·결합은 역순으로 되돌릴 수 있으며 소환 결과와 소환 횟수는 되돌리지 않는다.

## 8 특수 결합체와 결합식

여섯 계열의 서로 다른 두 계열을 고르는 조합은 총 15개다. 이번에는 그중 **전투 역할을 분명하게 바꿀 수 있는 6개 결합식**을 제안한다. 나머지 9개 계열 조합은 일반 전승만 제공한다. 모든 특성 조합마다 새 외형을 만들지는 않는다.

결합식의 두 계열은 순서에 관계없다. 양쪽 모두 분기 진화 상태여야 하며, 어느 분기를 골랐는지는 결합 가능 여부에 영향을 주지 않는다. 기준 동료 선택은 물려받을 전승 특성과 배치 위치만 결정한다. 결합체는 양쪽의 스킬을 모두 복사하지 않고 아래의 전용 스킬과 본래 특성을 갖는다.

| 융해술사 | 범위 피해와 제어를 스스로 연결 | 시전자 둘보다 공격 주기가 적고 한 명이 쓰러지면 두 역할을 함께 잃음 |
| 성가 기수 | 회복과 공격 강화를 한 자리로 압축 | 보호막 또는 피해 감소에 특화된 원본 분기의 기능 상실 |
| 원정 유격대장 | 집중 공격과 처치 후 회복 | 관통·연속 사격과 원본 기수의 지속 강화가 전용 명령으로 대체 |

기본 직업이 소환됐을 때 도감에는 이미 발견한 결합 경로를 보여준다. 새 결합은 양쪽 계열의 분기 진화를 처음 보유한 시점에 조합 힌트를 공개하고, 결합을 실제로 만들면 도감 기록을 완성한다. 미발견 결합을 외부 공략 검색만으로 알아내야 하는 구조는 피한다.

## 9 본래 특성과 전승 효과

모든 형태는 **본래 특성 하나와 전승 특성 최대 하나**를 가진다. 기본·분기·최종의 본래 특성은 계열 안에서 같다. 특수 결합체는 별도 본래 특성을 가진다. 본래 특성과 전승 특성의 같은 ID는 중복 적용하지 않는다.

전승 후 계수는 재료 동료의 능력치가 아니라 **받는 동료의 현재 능력치**를 사용한다. 능력치 변화가 없는 한 원본과 전승 후의 특성 효과는 같다. 전승받았던 특성은 다시 다른 동료에게 전달할 수 없다.

### 전승 조합을 읽는 법

아래 표는 기본 계열 기준의 첫 설계 의도다. 효율을 실측한 등급표가 아니다. ‘조건’은 해당 효과를 발동할 다른 동료·기술이 필요한 경우다. 진화와 유물에 따라 판단이 바뀐다.

| 기사 | 본래 보유 | 표식 동료 필요 | 평타 화상 | 시작 보호막·반격 | 근접 둔화 | 위기 보호막·반격 |
| 궁수 | 첫 돌진 방어 | 본래 보유 | 빠른 화상 공급 | 후열 보호 | 원거리 둔화 | 위기 보호 |

발동 불가능한 전승은 화면에 이유를 표시한다. 예를 들어 기본 궁수가 ‘한마음’을 받으면 아군 지원 스킬이 없어 발동하지 않는다. 향후 유격대장 결합을 목표로 보관하는 선택은 허용하되 현재 효과를 즉시 받는 것처럼 표시하지 않는다.

## 10 조합을 완성하는 예시

| 조합 | 성장·전승·유물 예시 | 전투에서 보여야 하는 연결 |
| --- | --- | --- |
| 보호막 반격 | 반격 기사 + 보호 사제. 기사에게 첫 빛 전승 | 시작 보호막 → 적의 공격 → 파쇄 → 사제의 보호막으로 다음 반격 준비 |
| 표식 집중 | 추적 사수 + 다른 원거리 공격수에게 집중 전승 | 낮은 HP 적 표식 → 화살과 다른 투사체 집중 → 처치 |
| 서리와 화염 | 결빙술사 + 잔화술사 또는 잔불을 전승받은 서리 동료 | 적이 느려져 불길 안에 오래 머묾 → 화상 누적 |
| 전열 회복 | 등불 성기사 + 수호 기수 | 전열에서 적을 붙잡고 회복 → 기수의 감소 효과로 지속 피해를 견딤 |
| 소수 정예 사격 | 원정 유격대장 + 관통 사수 | 표식 공개 → 강화된 기본 공격 → 처치 후 가까운 아군 회복 |
| 한 자리 복합 마법 | 융해술사 + 보호 사제 | 상태 효과와 폭발을 한 동료가 담당하고 사제가 시전 시간을 확보 |

v0.8의 ‘금 간 방패테’는 반격 기사와 함께 쓰면 두 충격파가 발생할 수 있다. 첫 시험에서는 유물 충격파를 위력 60%, 거리 1.5의 최대 3명, 동료별 재발동 3초로 두고 직업 파쇄와 합쳐 과도한 광역 피해가 되는지 확인한다. 유물 충격파는 또 다른 파쇄를 유발하지 않는다.

‘추적자의 매듭’은 표식 적 처치 시 거리 3.0 안 가장 가까운 다른 적에게 남은 표식 시간을 옮기는 방안이다. 최소 1초는 유지하고 다음 대상이 없으면 끝낸다. 전이 자체는 피해를 주지 않는다. ‘재를 담은 병’은 둔화된 적에게 화상을 새로 적용할 때 위력 50%의 추가 피해를 주고 대상별 3초의 재발동 간격을 둔다. 이 추가 피해는 다시 화상을 적용하지 않는다.

유물 세부 수치도 첫 시험값이며 직업표와 함께 조정한다. 특정 유물이 있어야 직업의 기본 기술이 작동하게 만들지는 않는다.

## 11 성장 공급과 제작 비용 검산

v0.8의 12전투 원정은 시작 동료 3명과 준비 2~12의 소환 11회를 모두 사용했을 때 기본 공급 14명이다. 다음 표의 ‘원본 동료’는 최종 명단에 남은 동료와 성장 재료를 합친 수다. 보너스 소환은 계산에 넣지 않는다.

| 결과 | 원본 동료 필요량 | 계산 |
| --- | --- | --- |
| 분기 진화 1명 | 3명 | 본체 1 + 재료 2 |
| 최종 진화 1명 | 7명 | 본체 1 + 첫 진화 재료 2 + 추가 재료 4 |
| 결합체 1명 | 6명 | 각 본체와 재료를 포함한 분기 3명분 + 분기 3명분 |
| 최종 1 + 분기 1 + 기본 3, 출전 5명 | 13명 | 7 + 3 + 3 |
| 결합 1 + 분기 1 + 기본 3, 출전 5명 | 12명 | 6 + 3 + 3 |
| 분기 4 + 기본 1, 출전 5명 | 13명 | 3 × 4 + 1 |
| 결합 2 + 기본 3, 출전 5명 | 15명 | 기본 공급 14명으로 불가 |
| 결합 2 + 기본 2, 출전 4명 | 14명 | 가능하지만 출전 한 자리를 비움 |
| 최종 1 + 결합 1 + 기본 3, 출전 5명 | 16명 | 기본 공급으로 불가. 출전 3명이라면 7 + 6 + 1 = 14 |

결합은 원본 여섯 명의 가치가 한 자리에 모이고, 일반 최종 진화는 일곱 명의 가치가 모인다. 결합체가 원본 두 분기의 스킬까지 모두 갖도록 하면 출전 자리를 절약하면서 기능을 거의 잃지 않아 지배적인 선택이 되기 쉽다. 전용 스킬로 바꾸고 단일 집중·다수 편성·특수 결합이 서로 다른 강점을 갖는지 비교한다.

**수량상 가능하다는 것과 무작위 소환으로 쉽게 만들 수 있다는 것은 다르다.** 일반 진화는 다른 계열도 재료로 쓸 수 있지만 결합에는 특정 두 계열의 본체가 필요하다. 원하는 본체가 나오지 않았을 때 일반 최종 진화로 전환해도 승리할 수 있어야 한다.

이동·기본 공격만 있을 때, 방어를 무시한 평타 초당 피해는 위력을 공격 간격으로 나눈 값이다. 기사 기본형은 약 14.81, 궁수는 약 21.82다. 보호막·화상·스킬·이동 손실을 제외한 비교일 뿐 실제 전투 기여도 순위로 쓰지 않는다. 방어만 고려한 기사 기본형의 유효 HP는 240 × 1.35 = 324이며 본래 특성의 감소 효과는 이 계산에 넣지 않았다.

## 12 외형과 애니메이션 설계

기존 중세풍 도트의 비율·색감은 유지한다. 각 형태를 이름과 색상만으로 구분하지 않고 무기·방패·자세·공격 궤적으로 구별한다. 아래는 제작 지시의 출발점이며 완성된 이미지나 스프라이트가 아니다.

| 계열 | 기본 외형 | 분기 A | 분기 B | 최종 외형과 분기 표현 |
| --- | --- | --- | --- | --- |
| 기사 | 짧은 검과 둥근 방패 | 큰 방패를 세우고 두 발을 고정 | 낮은 방패로 들이받는 전진 자세 | 등에 작은 봉화 장치. 수호는 방진, 반격은 방패 충격 동작 유지 |
| 궁수 | 짧은 활과 가벼운 망토 | 길고 단단한 활, 깊게 당기는 자세 | 짧은 활과 빠른 화살 교체 | 이중 곡선 활과 길잡이 표식. 분기별 장전 속도와 궤적 구별 |
| 불꽃 | 금속 고리가 달린 불씨 지팡이 | 큰 고리에 불꽃을 모아 던짐 | 낮은 화로를 열어 바닥으로 불씨 방출 | 이동식 봉화 고리와 긴 외투. 큰 폭발과 바닥 불길 동작 유지 |
| 사제 | 손에 든 등불과 짧은 의복 | 방패 모양 덮개의 등불 | 열리는 등불과 몸을 낮춘 회복 자세 | 몸 뒤에 펼쳐지는 세 등불. 방벽과 회복의 손동작 구별 |
| 서리 | 얼음 쐐기와 짧은 지도 두루마리 | 긴 얼음 봉으로 바닥을 짚음 | 짧은 쐐기를 빠르게 던짐 | 얼음 나침반과 어깨 보호구. 넓은 장판과 단일 쐐기 동작 유지 |

| 결합체 | 외형의 핵심 | 전용 공격 동작 |

기본 동작은 대기·걷기·공격·피격·쓰러짐이며 역할에 따라 방어·시전·기수 신호가 추가된다. 30형태 × 기본 22프레임이면 **약 660프레임**의 동료 작업량이다. 별도 스킬·분기별 최종 동작·적·보스는 이 수에 포함하지 않는다. 동일 몸체의 재사용 가능성은 한 계열을 실제 제작한 뒤 판단한다.

형태가 커져도 아군은 서로를 가리지 않는 범위에 두고, 보스는 일반 동료 약 1.8~2.3배의 크기부터 확인한다. 적 기본 방향은 왼쪽이다. 아군이 뒤쪽 공격을 하는 상황은 방향 전환과 공격 판정이 맞는지 따로 검증한다. 캐릭터 이름과 외형은 독자 디자인으로 발전시키고 제작 기록을 남긴다.

## 14 밸런스 검증과 실제 제작 순서

이 표의 수치는 공식을 연결하고 차이를 시험하기 위한 값이다. 실제 전투가 목표 시간에 끝나는지는 적 능력치·배치·접근 거리와 함께 결정된다. 다음 적·보스 상세표 없이 아군 수치만 최종 확정하지 않는다.

### 첫 검증 묶음

방패 기사·정찰 궁수·등불 사제와 기사 2분기를 먼저 만든다. 보호막이 깨질 때 반격이 한 번만 발생하는지, 덮어쓰기와 만료가 잘못 반격을 발생시키지 않는지, 두 기사가 같은 보호막을 중복 계산하지 않는지 확인한다. 이어 불꽃 계열을 추가하고 **잿불 검위** 하나로 결합 소모·특성 유지·되돌리기·저장 흐름을 확인한다.

| 비교 | 같은 조건에서 볼 것 |
| --- | --- |
| 수호 기사와 반격 기사 | 일반 적 무리, 단일 보스, 후열 공격에서 각 분기가 유리한 상황 |
| 두 분기 동시 출전과 결합 1명 | 원본 동료 6명분이라는 같은 비용에서 생존·처치 시간·빈 출전 자리의 가치 |
| 최종 집중과 여러 분기 | 13명 공급의 두 편성으로 최종 보스를 공략할 수 있는지 |
| 기본 특성 전승 6종 | 매번 같은 특성이 정답인지, 특정 조합이 실제로 발동하지 않는지 |
| 화상과 둔화 | 갱신·강도 우선·보스 감소가 설명대로 적용되는지 |
| 여러 난수의 소환 | 특정 직업을 못 얻어도 진화 경로를 바꾸어 진행 가능한지 |
| 저장과 되돌리기 | 원본·전승 특성·분기·결합 결과가 복구되고 동료나 보상이 복제되지 않는지 |

서로 다른 소환 난수 100개를 첫 탐색 단위로 잡고 전투별 출전 수, 분기·최종·결합 도달 시점, 소환권 미사용, 파티의 역할 공백을 기록한다. 이 정도 표본을 최종 밸런스의 통계적 보증으로 보지는 않는다. 특정 본체가 필요한 결합의 성공률과 일반 진화의 성공률은 따로 집계한다.

진화·결합형을 만들었는데 실제 역할이 달라지지 않으면 스킬과 공격 동작을 먼저 고친다. 숫자 조정은 그 역할이 보인 뒤 진행한다. 첫 완성 원정에서는 이 가운데 검증한 형태부터 쓰고, 나머지 직업을 미완성 상태로 모두 게임에 노출하지 않는다.
