# 심층 원정대 · UI 시안 01

2026-10-18 · 색감·세계관·캐릭터 외형을 검토하기 위한 첫 번째 디자인 제안입니다.

## 보기

- `index.html`을 브라우저에서 열거나, `node preview-server.mjs`로 실행한 뒤 `http://127.0.0.1:4173`에서 확인합니다.
- 미리보기 서버는 이 컴퓨터의 127.0.0.1에만 연결하고 지정한 시안 파일 여섯 개만 제공합니다.
- 데스크톱에서는 위의 세 버튼으로 준비·전투·보상 화면을 바로 확인합니다. 휴대폰 가로 화면에서는 게임 화면을 전체로 보여줍니다.

## 이번 디자인

- 도트 캐릭터가 숲 유적의 바닥 위에 직접 서 있는 넓은 가로 전장.
- 청록색 UI와 금색 주요 버튼, 읽기 쉬운 한글 글꼴.
- 상단은 구역·진행·골드, 하단은 선택한 동료·전술·전투 시작.
- 전투 중에는 편성 UI를 접고 전투 진행과 배속을 표시.
- 전투 뒤에는 배경을 남겨 두고 보상 세 가지와 확정 버튼을 표시.
- 작은 가로 화면에서는 적의 특징을 짧은 버튼으로 접고, 누르면 설명을 표시.

## 동작하는 부분

1. 동료를 직접 드래그하거나 동료 선택 후 전장의 빈 위치를 눌러 배치합니다. 키보드로 동료에 초점을 맞추면 방향키로도 이동합니다.
2. 배치 영역 밖이나 겹치는 위치는 취소하고 원래 위치로 돌아갑니다. 전투 중에는 배치를 잠급니다.
3. 전투 시작 → 이동·체력·피해 연출 → 보상 선택 → 다음 준비 화면으로 연결됩니다.
4. 전투 배속, 일시정지, 탭 비활성 시 자동 정지를 제공합니다.
5. 보상은 선택 후 확인해야 적용하며, 골드와 해당 동료의 수치가 변합니다.
6. 적의 특징과 전술 설명을 별도 창으로 확인합니다.

전투는 화면 흐름을 검토하기 위한 약 7초의 스크립트 연출입니다. 배치에 따른 실제 승패 판정, 길 찾기, 공격 계산, 난이도 균형, 영구 저장은 구현 범위에 포함하지 않았습니다. 원정 전술의 설명도 설계 예시이며 실제 전투 계산에는 연결되지 않았습니다.

## 아트 파일

배경과 캐릭터는 built-in image_gen으로 새로 생성했습니다. 참고작의 이미지나 캐릭터를 앱 자산으로 넣지 않았습니다.

- `assets/forest-battlefield.png` — 전장 배경.
- `assets/expedition-sprites-v2.png` — 6종 캐릭터, 실제 투명 배경. CSS로 각 영역을 표시합니다.
- `assets/ASSET-PROMPTS.md` — 정확한 생성 프롬프트·도구·파일 정보.
- `assets/expedition-sprites.png` — 최초 생성안 보존; 현재 화면에서는 사용하지 않습니다.

현재 캐릭터는 한 장면을 검토하는 컨셉 이미지입니다. 실제 게임 제작에는 통일된 픽셀 단위와 걷기·공격·피격 애니메이션을 갖춘 별도 스프라이트 작업이 필요합니다.

**권리 검토 상태:** 현재 6종 모두 출시 검토 전 시안입니다. 생성 기록 확인과 비침해 판단은 별개이며, 기존 캐릭터와의 개별 유사성 검토는 완료하지 않았습니다. 제작 출처와 검토 상태는 `assets/ASSET-PROMPTS.md`에 기록합니다. 사용자의 독자 캐릭터 제작 조건에 따라 우려가 남는 디자인은 출시 대상에서 제외하고 다시 설계합니다.

## 확인한 사항

- JavaScript 구문 검사 통과.
- 브라우저 실행 오류 없음.
- 드래그 이동 후 좌표 변경, 전투 중 편성 잠금과 보상 진입 확인.
- 보상 확정 시 골드 18→22, 웨이브 4→5, 선택 동료 체력 220→232를 확인.
- 작은 휴대폰 가로 화면에서 안내와 캐릭터가 겹치던 부분을 수정.
- 화면 캡처는 `previews` 폴더에 있습니다.

실제 휴대폰의 터치·노치·프레임 성능을 검증한 결과는 아닙니다. 게임 콘텐츠와 상품 구조는 기존 기획서 v0.3에서 이어서 검토합니다.
