ORIGINAL SYNTHESIZED PROTOTYPE AUDIO

These five WAV files were synthesized specifically for this project using only
Python standard-library math, seeded pseudorandom noise, struct, and wave.
No recordings, external sound libraries, downloaded music, or sampled assets
were used. There are no third-party source-audio attribution requirements.

Generator: tools/synthesize-combat-audio.py (relative to the repository root)
Regenerate: python tools/synthesize-combat-audio.py
Verify only: python tools/synthesize-combat-audio.py --verify-only

Format: mono, 44,100 Hz, signed 16-bit PCM WAV; silent endpoints with smooth fades.
Every sound has an independent, fixed random seed. Peak amplitude is below 0.65.

Unity resource paths omit the .wav extension:
Audio/melee_hit, Audio/arrow_launch, Audio/arrow_hit, Audio/defeat, Audio/ui_confirm

Validation: the generator checks channel count, sample rate, PCM format,
duration, sample peak, non-silent content, and quiet/silent edges.
An audible listening review and an actual Unity/Android playback test have not
been performed. These are first-pass assets for an in-game listening review.
Per-voice headroom does not prevent clipping when many sounds overlap: runtime
mixing still needs conservative gain, concurrent-voice limits, and device review.
