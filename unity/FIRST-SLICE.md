# 잔불 원정대: 첫 전투 플레이 구간

기획서 0.6의 **첫 조합**을 시험하는 한 전투 빌드다. 출전 동료는 방패 기사·등불 사제·불꽃 마법사, 적은 성문 골렘이다.

## 플레이 방법

1. 준비 화면에서 왼쪽 아군을 직접 드래그해 배치한다. 오른쪽의 골렘은 이동할 수 없다.
2. 대기 기사·사제·마법사 각 1명 중 두 명을 `USE KNIGHT/PRIEST/FIRE MAGE`로 훈련에 쓴다. 화면 설명대로 `USE` 버튼을 누르면 해당 대기 동료를 소비하고 기사의 훈련 진행도가 1 오른다.
3. 훈련 2회 후 `COUNTER` 또는 `GUARDIAN`을 고른다. `PASS TO`로 받을 출전 동료를 고르고 남은 대기 동료의 본래 특성을 전승할 수도 있다. 전투 전 `UNDO`로 마지막 선택부터 되돌린다.
4. `FIGHT`로 자동 전투를 시작한다. 골렘의 붉은 선은 0.8초 뒤 충격 방향을 표시한다. 전투 중 일시정지와 1·2배속을 사용할 수 있다.
5. `RETRY`는 같은 성장 선택으로 다시 배치하고 싸운다. 다른 진화 분기를 비교하려면 `NEW RUN`을 누른다.

기사는 시작 보호막과 HP가 낮아졌을 때 발동하는 `버팀`을 가진다. 반격 기사는 적의 직접 피해로 보호막이 깨질 때 전방 범위에 피해와 둔화를 주며, 수호 기사는 가까운 아군에게 주기적으로 보호막을 준다. 사제는 보호막을, 마법사는 화상 공격을 사용한다. 보호막은 한 개만 유지되며 더 큰 새 보호막으로 교체된다. 전승 특성은 평타나 피격 조건에 따라 발동한다.

## 검증과 남은 범위

- `tests/CombatCoreSmoke/run-smoke.ps1`: 14개 전투·준비 시나리오, 285개 단언 통과.
- `tools/check-unity-project.ps1`: Unity 6000.3.24f1 배치 임포트와 C# 컴파일 통과.
- Android APK는 `tools/build-first-slice.ps1` 또는 Unity의 **Expedition → Build Android Test APK** 메뉴에서 만든다. 빌드 결과와 실기기 확인은 각 실행 로그로 판단한다.
- Galaxy Buddy2에서 훈련 2회·반격/수호 진화·특성 전승·되돌리기·골렘 예고·반격 파동·승리·재시도·새 원정을 확인했다. 실행 로그에서 Unity 오류와 FATAL 패턴은 관찰되지 않았다. 캡처와 로그는 `Logs/astra-device/`에 로컬로 보관한다.

기존 중세풍 시트를 사용한다. 불꽃 마법사는 등불 캐릭터를 주황색으로 표시한 **임시 외형**이고, 성문 골렘도 시트의 자동인형을 임시로 사용한다. 진화 전용 실루엣과 애니메이션은 아직 없다.

이 빌드는 한 전투에서 훈련·전승·분기·배치·보스 공격을 확인하는 범위다. 6전투 원정, 영입, 나머지 계열·진화, 영구 진행은 구현되지 않았다. `불씨` 평타의 2초 적용 제한은 현재 시전자별로 처리되며 다수 적에 대한 대상별 제한은 다음 확장에서 맞춘다.
